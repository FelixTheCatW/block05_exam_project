# Прогноз калорий по макронутриентам

Консольное приложение на Python для прогнозирования общего количества потребляемых калорий на основе макронутриентов (углеводы, жиры, белки) с использованием линейной регрессии.

## Описание

Программа загружает данные из файла `diaries_ai.parquet`, очищает выбросы методом межквартильного размаха (IQR), обучает модель линейной регрессии и выводит метрики качества. Также предусмотрен скрипт для загрузки сохранённой модели и выполнения предсказаний на новых данных.

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта.
2. Установите зависимости:

```bash
pip install pandas numpy scikit-learn joblib
```

# Использование
## Обучение модели

Запустите основной скрипт:
```bash

python calories_forecast.py
```
## Скрипт:

    загружает данные из data/diaries_ai.parquet;

    фильтрует выбросы;

    обучает модель на признаках total_carbs, total_fat, total_protein;

    выводит метрики (MAE, RMSE, R²) и коэффициенты модели;

    сохраняет модель и список признаков в папку models/, а тестовые данные — в data/test_data.parquet.

## Предсказание на новых данных

Скопируйте тестовый файл в data/test_data.parquet или укажите свой путь. Затем выполните:
```bash

python predict_calories.py
```
Скрипт:

    загружает сохранённую модель и признаки;

    применяет модель к тестовым данным;

    выводит предсказания и метрики (если известны фактические значения);

    сохраняет предсказания в predictions.csv.
